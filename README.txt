Tangled — Instructor Presentation Prototype

Open index.html in Chrome.

This is a clickable front-end prototype with mock data.

Main presentation flow:
Teacher overview -> Discover more on a topic -> Course setup -> Student tutor -> Assessment.

Design intent:
- Keep the teacher dashboard intentionally minimal.
- Topic cards are side-by-side.
- Only the topic, status, short reason, and one useful signal appear initially.
- Detailed evidence is hidden behind "Discover more".
- "Still unclear" is an evidence signal, not a notification.
- Project name is Tangled.
